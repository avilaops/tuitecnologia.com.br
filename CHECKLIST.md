# ✅ Checklist de Lançamento - Tui Tecnologia

Use este checklist antes de publicar o site em produção.

- [ ] Nome da empresa está correto em todas as páginas

- [ ] E-mail de contato atualizado em todas as páginas

- [ ] Endereço completo está correto

- [ ] Links de redes sociais funcionando
  - [ ] Facebook

- [ ] Cores personalizadas no CSS
- [ ] Ícones adequados selecionados

- [ ] Logo em alta resolução

- [ ] Todos os produtos listados
- [ ] Preços atualizados
- [ ] Descrições dos produtos corretas
- [ ] Links de produtos funcionando
- [ ] Botões de solicitação testados

## 🔧 Funcionalidades

- [ ] Menu de navegação funcionando
- [ ] Menu mobile testado
- [ ] Formulário de contato testado
- [ ] Filtros de produtos funcionando
- [ ] Links internos funcionando

- [ ] Title tags únicos em cada página
- [ ] Meta descriptions em todas as páginas
- [ ] Alt text em todas as imagens
- [ ] URLs amigáveis
- [ ] Sitemap.xml criado (opcional)
- [ ] Robots.txt configurado (opcional)

- [ ] Testado em Desktop (1920px+)

- [ ] Testado em Mobile (375px)
- [ ] Testado em iPhone
- [ ] Testado em Android

## 🌍 Navegadores

- [ ] Chrome
- [ ] Firefox
- [ ] Safari
- [ ] Edge
- [ ] Opera (opcional)

## ⚡ Performance

- [ ] Imagens otimizadas (comprimidas)
- [ ] CSS minificado (produção)
- [ ] JavaScript minificado (produção)
- [ ] Tempo de carregamento < 3 segundos
- [ ] Google PageSpeed Score > 80

## 🔒 Segurança

- [ ] HTTPS configurado
- [ ] Formulário com validação

## ♿ Acessibilidade

- [ ] Todas as imagens têm alt text
- [ ] Contraste de cores adequado

- [ ] Formulários com labels corretos

## 📝 Conteúdo

- [ ] Textos revisados (sem erros de português)
- [ ] Informações legais incluídas

- [ ] Política de privacidade (se aplicável)
- [ ] Copyright atualizado com ano correto

- [ ] Domínio registrado
- [ ] DNS configurado
- [ ] Hosting escolhido
- [ ] Arquivos enviados
- [ ] Site acessível via domínio
- [ ] Redirecionamento www configurado
- [ ] Certificado SSL instalado

## 📊 Analytics

- [ ] Google Analytics instalado
- [ ] Google Search Console configurado
- [ ] Facebook Pixel (se aplicável)
- [ ] Hotjar ou similar (opcional)

## 📧 E-mail/Formulários

- [ ] Formulário de contato enviando e-mails
- [ ] E-mails sendo recebidos
- [ ] Auto-resposta configurada
- [ ] Proteção anti-spam ativa

## 🔍 Testes Finais

- [ ] Todos os links externos funcionando
- [ ] Todos os links internos funcionando
